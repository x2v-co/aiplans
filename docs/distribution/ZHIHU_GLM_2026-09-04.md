## 回答正文

因为“模型开源”和“官方推理服务低价”是两件事。

开源解决的是权重、许可证和自行部署的可行性；API 售卖的是已经运行起来的推理服务，
价格还要覆盖 GPU、扩缩容、并发、网络、可用性、运维和支付结算。权重可以下载，并不
意味着托管推理的边际成本会自动归零。

判断 GLM API 到底贵不贵，至少要拆开三个问题。

第一，比较的是不是同一个模型版本。GLM 5.2、5.3、Flash、Batch 和免费路由不是同一
种商品。把这些行只按“GLM”排序，会把版本差异和限额一起藏掉。

第二，比较的是裸单价还是自己的工作负载。以 100 万输入 token 加 25 万输出 token 为
例，计算式是：

```text
示例成本 = 输入单价 + 输出单价 * 0.25
```

我在 2026-09-03 核验的快照里，OpenRouter 的 GLM 5.2 是 US$0.97 输入、US$3.04
输出，对应示例成本约 US$1.73。同页记录的免费路由虽然显示 US$0，但它有独立的限额
和可用性，不能当成稳定生产价格。

作为当前官方渠道的参照，智谱 GLM 5.3 是人民币 8 元输入、28 元输出，同一工作负载
是 15 元，折算约 US$2.17。这里不能据此说 5.2 或 5.3 谁“更值”，因为它们不是同一
版本；这个例子只是说明模型、渠道和币种必须先对齐。

第三，自部署并不等于免费。低利用率时，自建机器的闲置成本、显存、部署和运维可能比
按量 API 更贵；只有在负载稳定、利用率足够高，并且团队能承担服务保障时，自部署的
单位成本优势才可能体现出来。比较时应该把 GPU 折旧或租金、电力、运维时间和峰值冗余
都算进去，而不是只拿开源模型的下载价格与 API 账单比较。

所以更准确的结论是：开源让你多了“自己提供推理服务”的选择，但没有承诺官方 API
必须按成本价出售。对个人或小团队，先按真实输入/输出比例算按量成本；对稳定的大流量，
再拿同一个模型版本做自部署总成本对比，结论会可靠得多。
