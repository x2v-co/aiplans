```text
Hi Console team,

I maintain AIPlans, a free and open-source tool for choosing a current leading
AI model and then comparing that exact model across API channels:

https://aiplans.dev/en/compare/models?utm_source=newsletter&utm_medium=referral&utm_campaign=model_selection_2026_09&utm_content=editorial_pitch

the exact model across direct providers, clouds, and aggregators.

The code and data pipeline are available at https://github.com/x2v-co/aiplans.
I would be happy to provide more detail on the data model, verification process,
or current coverage.

Disclosure: I am the project's maintainer.

Thanks,
```

## Changelog News

Verified route: `https://changelog.com/news/submit`

The site explicitly encourages submitting one's own work, but excludes
commercial products and requires a Changelog account. Submit the open-source
repository and describe the technical data problem; do not frame it as a paid
service or tutorial.

URL:

```text
https://github.com/x2v-co/aiplans
```

Title:

```text
AIPlans: an open-source, auditable index of AI API prices
```

What's interesting about it:

```text
AI API prices are difficult to compare because the same model can be sold by a
direct provider, cloud platform, or aggregator with different currencies,
cache tiers, batch discounts, and model aliases. AIPlans currently normalizes
343 priced models across 479 available channels from 21 providers while
retaining each source price and verification date. The repository includes the
Next.js application and the scraping, normalization, and audit pipeline. It is
free to use and MIT licensed.
```
