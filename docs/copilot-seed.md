```sh
npm run seed:copilot         # default: read-only transaction, field-level preview
npm run seed:copilot:apply   # explicit: serializable transaction, idempotent writes
```

The seed reuses GitHub's provider/product ID, protects unrelated records and manual model links, and writes derived preview-pool links only for models already in the catalog. Missing models are skipped; rerun after catalog additions or use the usual mapping materializer. If no pool model exists, the selector remains NULL until the seed is rerun. The default dry-run sets the same serializable transaction read-only and issues SELECTs only. No database was accessed as part of this refresh; tests use an in-memory SQL fixture.

## Schema gap

The current fields cannot encode a monthly **per-user seat fee plus a shared, model-priced enterprise usage budget**, organization-wide credit pooling, the GHE license dependency, enterprise-wide billing-model exclusivity, staged sales availability, or which features survive budget exhaustion. These conditions are recorded in notes/features rather than adding schema or inventing a new billing enum.

Standalone keeps `pricing_model=subscription`, `price_unit=per_month` and supported `billing_granularity=flat_monthly` for the seat fee only, with `is_contact_sales=true` for sales-assisted availability. `included_credits=0`, `included_usage_amount=0`, and `quotas=[]` explicitly convey no included allowance; the economics helper returns `none_published` and computes no usage-per-dollar rate. `monthly_api_credit_usd` and `monthly_api_credit_status` stay NULL: Copilot usage is not an included external API balance, and `needs-verification` would incorrectly trigger copy saying that monthly API credit is included. Business/Enterprise credit quotas are per-user contributions; their organization-wide pooling is explained in the quota notes.

Consumer-facing behavior was checked in `provider-copy.ts`, `pricing-seo.ts`, `subscription-search.ts`, `compare-plans-index.ts`, `compare-plans.ts`, the comparison/provider views, `plan-economics.ts`, and `data-trust.ts`. Contact-sales rows are excluded from provider cheapest-paid prose, subscription SEO price floors, and featured comparison cards. Trust labels recognize contact-sales pricing and do not treat a later `[needs-verification]` annual/region/payment note as withholding the verified seat price. Standalone's first feature and coverage note state the separate metered charge; detailed Copilot notes are available on comparison surfaces. Some model comparison summaries still rank numeric seat prices without pricing the usage budget or excluding contact-sales rows; price cards can also suppress the numeric seat fee behind “Contact sales.” Data alone cannot correct these generic presentation limits. The $10 published seat fee remains stored and explained in visible features/notes, and no $0 GHE bundle is introduced into ranking.
