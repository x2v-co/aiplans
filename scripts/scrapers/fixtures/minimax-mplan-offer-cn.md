# M Plan 月付首月五折

> 了解活动时间与活动规则。

M Plan 上线期间，Go、Explore 和 Build 的月付订阅首月 5 折，次月起按原价自动续费。

## 活动时间

即日起至10月14日

## 活动规则

* **适用范围**：本活动适用于 Go、Explore 和 Build 的月付订阅，年付不参与。
* **活动价格**：首月按下表中的活动价支付，次月起按原价续费。

| 档位 | 首月活动折扣 | 原价 |
| :- | :- | :- |
| Go | 5 折 | ¥49/月 |
| Explore | 5 折 | ¥119/月 |
| Build | 5 折 | ¥469/月 |

* **新购**：按目标档位的首月活动价支付。
* **升级**：活动期间升级到 M Plan 月付档位，包括从 Token Plan 升级，以及在 M Plan 内升级到更高档位，应付金额为目标档位的首月活动价减去当前订阅的剩余价值。
* **续费**：首月结束后，订阅将按目标档位的原价自动续费。如不需要续费，可在当前周期结束前关闭自动续费，详见 [升级与取消](/docs/m-plan/change-plan)。
