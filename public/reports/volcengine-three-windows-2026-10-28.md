## 测量过程和计算

1. 刷新已登录控制台，确认 Coding Plan Pro，记录三个窗口的基线和重置倒计时。
2. 通过本地 Claude Code 和既有 Coding Plan 配置调用官方 coding 端点；独立临时工作目录，关闭工具和会话持久化。使用合成代码审查任务，每次约 41,249 个普通输入 tokens。
3. 每批结束暂停调用、刷新控制台；首批和第二批分别复读一次，第三批结束复读两次，读数均保持不变。
4. 从 30 份原始结果事件独立核对成功状态、模型和用量，确认与逐次账本一致。没有将 assistant 事件的占位用量与 result 用量重复相加。
5. 对每个窗口独立计算：总额度点估计 = 1,258,698 × 100 ÷ 已用比例增量（百分点）。
6. 显示分辨率为 0.01 个百分点，假设每次四舍五入误差 ±0.005，则两端差值误差 ±0.01；上下界 = tokens × 100 ÷（增量 ±0.01）。不是统计置信区间。
